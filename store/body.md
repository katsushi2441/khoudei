### 先に、このデータの限界を書きます

**空き状況は分かりません。** 公表データに入っていないからです。画面に出している定員は**1日あたりの利用定員**で、いま受け入れられる人数ではありません。

**支援の内容も分かりません。** どんな療育をしているか、送迎があるか、どんな資格の職員が何人いるかは公表データにありません。見学と面談でしか分からないことです。

**消えた事業所が廃止したかどうかも分かりません。** 公表データから消えた、という事実だけを書いています。

**公表件数が増えた＝事業所が増えた、でもありません。** 自治体の登録が進んだぶんが混ざります。

分からないものを分かったように書かない。それがこの道具の設計です。

### 何ができるか

**住所を入れると、通える範囲の事業所が近い順に出ます。**

| 収録しているサービス | 事業所数 |
|---|---|
| 放課後等デイサービス | 25,020 |
| 児童発達支援 | 16,993 |
| 障害児相談支援 | 9,856 |
| 保育所等訪問支援 | 3,995 |
| 居宅訪問型児童発達支援 | 357 |
| 医療型児童発達支援 | 37 |

2026年3月末時点、合計56,258事業所。**緯度経度が全件そろっている**ので、住所からの距離がそのまま出ます。定員・営業時間（平日／土／日／祝）・定休日・電話・事業所のサイトも表示します。

あわせて、次のページが最初から入っています。

- **都道府県ページ（47）** … 市区町村別の一覧表と、半年ごとの公表件数の推移
- **市区町村ページ（1,400超）** … 事業所一覧・推移・消えた事業所。政令市と東京23区は**区ごとのページ**も
- **事業所ページ（56,258）** … 定員・連絡先・近くの事業所
- **CSV と JSON API** … `/data/offices.csv`、`/api?q=住所`
- **sitemap.xml・llms.txt** … 検索エンジンとAI検索の両方に向けた索引

### 増えた側だけを見ても、この分野は分かりません

放課後等デイサービスの公表件数はこう動いています。

| 時点 | 公表件数 |
|---|---|
| 2021年11月末 | 14,663 |
| 2026年3月末 | 25,020（**1.71倍**） |

急増しています。ところが**同じ期間に公表データから消えた事業所も3,114か所**あります。

| 最後に公表された時点 | 消えた放課後等デイ | その定員の合計 |
|---|---|---|
| 2024年3月末より後 | 1,947か所 | 15,805人分 |
| それ以前（2年半） | 1,167か所 | 9,133人分 |

入ってくる事業所と出ていく事業所が、どちらも増えています。合計の数字だけを見ていると、この入れ替わりは見えません。市区町村ごとに、消えた事業所の名前と「最後に公表された時点」が一覧で出ます。

### なぜ要るのか

子どもに合う放課後等デイサービスを探すとき、多くの家庭は相談支援専門員に聞くか、事業所のサイトを1件ずつ開いています。国は全国のデータをオープンデータとして出していますが、**サービス種別ごとにZIPで分かれたCSV**で、住所から引ける形にはなっていません。

この道具は、そのCSVを住所から引ける形に変えただけです。ただし、変えるときに「分からないもの」を混ぜないようにしています。

### 置き方（3分）

1. `khoudei.php` と `khoudei_data/` を置く
2. その階層の `.htaccess` に `AddHandler php-script .php` を書く（共有サーバーの既定がPHP5.6のことがあるため）
3. `https://あなたのドメイン/khoudei.php/` を開く

**データベースサーバーも常駐プロセスもポートも要りません。** 必要なのはPHP 8とPDO SQLiteだけです（どちらも標準で入っています）。書き込み権限も不要です。

住所から緯度経度を出すのに国土地理院の住所検索を使いますが、つながらない環境では「取得できませんでした」と表示して止まります（「事業所がありません」とは書きません）。事業所の座標は最初からデータに入っているので、外部のジオコーディングサービスは要りません。**判定は置いた場所で完結し、外部のAIやAPIには何も送りません。**

### 更新のしかた（年2回）

WAM NETのオープンデータは毎年3月末・9月末に更新されます。同梱のPythonを2本動かせば、新しいデータベースができます。

```
python3 scripts/fetch_sfk.py --all
python3 scripts/build_db.py
```

### こんな方に

- **保護者向けの相談窓口・支援団体** … 「通える範囲にどこがあるか」を距離つきで見せられます
- **相談支援事業所** … セルフプラン作成の相談で、近隣の選択肢を一覧にして渡せます
- **議員事務所・行政** … 自分の自治体で何か所増え、何か所消えたのかを事業所名つきで示せます。CSVはそのまま委員会の資料に使えます
- **福祉系のメディア** … 自分の名前で公開できます（MITライセンス）
- **自治体のDX担当** … 国のオープンデータを住民が引ける形にする例として、そのまま流用できます

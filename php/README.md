# Kurage 放課後等デイサービスナビ（khoudei）

住所を入れると、通える範囲の **放課後等デイサービス・児童発達支援・保育所等訪問支援・障害児相談支援** の
事業所を距離順に返します。定員・営業時間・電話・サイトつき。市区町村ごとに公表件数の推移と、
「前は載っていたのに、いまは載っていない事業所」も出ます。

デモ: <https://kurage.exbridge.jp/khoudei.php/>

## 置き方

PHPが動くレンタルサーバーに、この3つを置くだけです。データベースサーバーも常駐プロセスも要りません。

```
khoudei.php
khoudei_data/khoudei.sqlite    ← 約41MB
khoudei_data/.htaccess         ← Require all denied（SQLite の直読みを止める）
images/ogp/khoudei.png         ← OGP画像（khoudei_data 配下は拒否するので別の場所に置く）
```

必要なのは **PHP 8 と PDO SQLite** だけです（どちらも標準で入っています）。

heteml をお使いの場合は、置いた階層の `.htaccess` に次の1行が要ります。無いと PHP 5.6 で動いて
エラーになります。

```apache
AddHandler php-script .php
```

`khoudei.php` の先頭にある `$SITE`（表示名）と `$OGP`（OGP画像のURL）を、ご自分のサイトに合わせて
書き換えてください。

## 画面

| URL | 内容 |
|---|---|
| `/` | 住所から探す（`?q=住所&kind=種別&km=範囲`） |
| `/pref/{都道府県}` | 市区町村別の一覧・推移・消えた事業所 |
| `/city/{都道府県}/{市区町村}` | 事業所一覧（政令市は `/{区}` まで） |
| `/office/{id}` | 事業所ごとのページ |
| `/gone` | 公表データから消えた事業所（全国・都道府県別） |
| `/api?q=住所` | JSON |
| `/data/offices.csv` `/data/gone.csv` | CSV |
| `/llms.txt` `/robots.txt` `/sitemap.xml` | AI検索・検索エンジン向け |

住所から緯度経度を出すのに国土地理院の住所検索だけを使います。事業所の座標は最初からデータに
入っているので、外部のジオコーディングサービスは不要です。判定は置いた場所で完結し、
外部のAIやAPIには何も送りません。

## データを新しくする

WAM NET のオープンデータは毎年 **3月末・9月末** に更新されます。同梱の2本を順に動かすと、
新しい `khoudei.sqlite` ができます。

```bash
python3 scripts/fetch_sfk.py --all   # ZIP を落とす
python3 scripts/build_db.py          # → khoudei_data/khoudei.sqlite
```

配布 ZIP は「時点 × サービス種別」で分かれています。`_65` は放課後等デイサービスであって
香川県ではありません。CSV は **UTF-8 BOM付き**です（cp932 でも decode 自体は通ってしまい、
列名が化けたまま動きます）。

## この道具が言えること／言えないこと

| | |
|---|---|
| 言える | 公表データに載っている事業所と、その定員・所在地・連絡先 |
| 言える | ある時点の公表件数と、番号が公表データから消えたこと |
| **言えない** | **空き状況**（公表されていません。定員は1日あたりの利用定員です） |
| **言えない** | **支援の内容・職員の配置・送迎の有無**（公表データにありません） |
| **言えない** | **廃止したかどうか**（消えた理由は公表されていません） |

利用には市区町村が出す**受給者証**が要ります。

放課後等デイサービスの公表件数は 2021年11月末の 14,663 から 2026年3月末の 25,020 へ **1.71倍**に
なりました。ただしこれには自治体の登録が進んだぶんが混ざるので、事業所がそのまま1.7倍になったとは
書きません。同じ期間に公表データから消えたのは 3,114か所で、**2024年3月末より後だけで 1,947か所**
（定員15,805人分）です。**増えた側だけを見ても、この分野の動きは分かりません。**
